# AT TTY Server

Сервер принимает AT-команды через виртуальный последовательный порт (PTY) и
возвращает ответы из словаря.

## Сборка

Из корня проекта:

```bash
cmake -S . -B build/Debug -DCMAKE_BUILD_TYPE=Debug
cmake --build build/Debug
```

Если каталог `build/Debug` уже настроен, достаточно выполнить:

```bash
cmake --build build/Debug
```

## Запуск

Запустите сервер из корня проекта, чтобы словарь находился по пути
`data/expect.txt`:

```bash
./build/Debug/at_server
```

В выводе появится имя PTY, например:

```text
Listening on: /dev/pts/1 (fd=3)
```

Оставьте сервер запущенным. В другом терминале подключитесь к указанному
устройству:

```bash
screen /dev/pts/1 115200
```

Используйте фактический путь из вывода текущего запуска. После перезапуска
сервера путь может измениться.

Для выхода из `screen` нажмите `Ctrl+A`, затем `K`, затем `Y`.

## Проверка вручную

Введите команды и нажимайте Enter:

```text
AT
ATE0
ATE1
ATI
AT+COPS
AT+CPIN
```

Ожидаемые ответы определяются файлом `data/expect.txt`. Формат записи:

```text
pattern=answer
```

Поддерживаются паттерны `.`, `*`, диапазоны и наборы в квадратных скобках,
а также экранирование через `\\`. Для неизвестной команды сервер отвечает
`ERROR`.

Ввод в `screen` отображается благодаря эхо, реализованному сервером. Ответы
и принятые команды также видны в терминале, где запущен сервер.

## Автотесты

Запустите тесты из каталога сборки:

```bash
ctest --test-dir build/Debug --output-on-failure
```

Ожидаемый результат:

```text
100% tests passed
```
