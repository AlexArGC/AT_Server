# AT TTY Server

Сервер принимает AT-команды через виртуальный последовательный порт (PTY) и
возвращает ответы из словаря.

## Сборка

Из корня проекта:

```bash
cmake -S . -B build/Debug -DCMAKE_BUILD_TYPE=Debug
cmake --build build/Debug
```

Если каталог `build/Debug` уже настроен, достаточно выполнить:

```bash
cmake --build build/Debug
```

## Запуск

По умолчанию сервер создает виртуальную пару PTY. Запустите его из корня
проекта, чтобы словарь находился по пути `data/expect.txt`:

```bash
./build/Debug/at_server
```

Можно передать путь к существующему TTY первым аргументом:

```bash
./build/Debug/at_server /dev/ttyUSB0
```

В выводе появится имя PTY, например:

```text
Listening on: /dev/pts/1 (fd=3)
```

Оставьте сервер запущенным. В другом терминале подключитесь к указанному
устройству:

```bash
screen /dev/pts/1 115200
```

Используйте фактический путь из вывода текущего запуска. После перезапуска
сервера путь может измениться.

Для выхода из `screen` нажмите `Ctrl+A`, затем `K`, затем `Y`.

## Проверка вручную

Введите команды и нажимайте Enter:

```text
AT
ATE0
ATE1
ATI
AT+COPS
AT+CPIN
```

Ожидаемые ответы определяются файлом `data/expect.txt`. Формат записи:

```text
pattern=answer
```

Пустые строки и строки, начинающиеся с `#`, игнорируются. Сопоставление полное:
вся введенная строка должна соответствовать паттерну. Поддерживаются:

* `.` — ровно один любой символ;
* `*` — ноль или больше любых символов;
* `[abc]` — один символ из набора;
* `[0-9]` — один символ из диапазона;
* `[^0-9]` — один символ, не входящий в диапазон;
* `\\` — экранирование специального символа.

Например, записи из `data/expect.txt`:

```text
AT+ECHO.*=OK
AT+DATA*=OK
```

Первая запись соответствует `AT+ECHO` и одному или более символам после него,
а вторая — `AT+DATA` с любым необязательным продолжением. Для неизвестной
команды сервер отвечает `ERROR`. Если подходят несколько записей, используется
первая по порядку в файле.

Ответ из словаря отправляется с добавлением `CRLF`. Последовательности `\\n`,
`\\r` и `\\t` в ответе преобразуются в управляющие символы; `\\n` дает перевод
строки `CRLF`.

Команда `AT+SHUTDOWN` завершает работу сервера и не ищется в словаре.

Ввод в `screen` отображается благодаря эхо, реализованному сервером. Ответы
и принятые команды также видны в терминале, где запущен сервер.

## Автотесты

Запустите тесты из каталога сборки:

```bash
ctest --test-dir build/Debug --output-on-failure
```

Ожидаемый результат:

```text
100% tests passed
```
